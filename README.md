# iris-flower-classification-knn
Iris flower classification using the K-Nearest Neighbors (KNN) algorithm with Python and scikit-learn.
# Iris Flower Classification using KNN

## About the Project
I worked on this project to understand how a basic machine learning
classification problem works using the Iris dataset.
I used the K-Nearest Neighbors (KNN) algorithm to classify Iris flowers
into different species based on their measurements.

## Dataset
The Iris dataset contains 150 samples and 4 features:
- Sepal length
- Sepal width
- Petal length
- Petal width

The three flower species are:
- Setosa
- Versicolor
- Virginica

## What I Did
- Loaded the Iris dataset using Scikit-learn
- Explored the dataset using Pandas
- Checked the dataset shape, features and target classes
- Used basic statistical analysis with `describe()`
- Created a scatter plot to visualize the data
- Split the data into training and testing sets
- Applied the K-Nearest Neighbors (KNN) algorithm
- Checked the accuracy of the model

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Result
The KNN model achieved **100% accuracy** on the test data used in this
project.

## What I Learned
This project helped me understand the basic steps involved in a
machine learning classification problem, including working with a
dataset, exploring data, training a model and checking its accuracy.
